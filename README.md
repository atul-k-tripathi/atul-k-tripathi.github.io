# Atul Kumar Tripathi — Academic Website

A static, research-first academic website for GitHub Pages.

## Files

- `index.html` — home
- `research.html` — research interests and projects
- `publications.html` — publication record
- `cv.html` — online CV summary
- `style.css` — responsive academic styling
- `script.js` — mobile navigation
- `Atul_Academic_CV_Final.pdf` — the supplied two-page CV

## Publish with GitHub Pages

1. Create a public repository named `atul-k-tripathi.github.io`.
2. Upload **all files in this folder directly into the repository root**.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then save.
7. Your website will be served at:
   `https://atul-k-tripathi.github.io`

No Node.js, npm, build command, or server is required.

## Source and accuracy

The biographical and academic content is based on the supplied final CV. The publication metadata and DOI were cross-checked against the Springer proceedings record. Profile links use the exact canonical URLs supplied by the author.

GitHub is intentionally not linked because no exact GitHub profile URL was supplied; this avoids inventing or guessing an identity.

## Design principle

The site intentionally uses restrained typography, whitespace, and evidence-led language. It avoids inflated claims, fabricated metrics, generic portfolio language, unnecessary animations, and unsupported credentials.
