## Publish with GitHub Pages

1. Create or open the public repository `atul-k-tripathi.github.io`.
2. Upload the **contents of this folder directly into the repository root**.
3. Commit to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select `main` and `/ (root)`, then save.
7. The site will be available at `https://atul-k-tripathi.github.io`.

No Node.js, npm, build command, or server is required.

## Quality and authenticity

The website is intentionally restrained and evidence-led. It avoids fabricated metrics, unsupported credentials, exaggerated claims, stock imagery, skill percentages, and portfolio-style hype. Academic and biographical content follows the supplied final CV; the publication DOI and proceedings metadata were previously cross-checked against the Springer record.
